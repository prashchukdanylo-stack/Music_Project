# Fluire - website for listening to music

Fluire — це простий музичний веб-додаток на React, де можна обирати будь-які треки і насолоджуватися музикою у красивому інтерфейсі.

## **Особливості**
- Генератор випадкових треків без повторів поспіль.  
- Сторінка відтворення пісні (`/song`) з кнопками Play/Pause, прогрес-баром та регулюванням гучності.  
- Маршрутизація між HomePage та Song page.  
- Автоматична обробка завершення треку та оновлення прогресу.  


## **Технології**
- React  
- React Router DOM  
- HTML5 `<audio>`  
- CSS для стилів та Player UI

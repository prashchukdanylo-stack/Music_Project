# 🎵 React Music Player

Цей проєкт — це повноцінний веб-плеєр для прослуховування музики, створений за допомогою React. Додаток має сучасну архітектуру, підтримує збереження стану між сесіями та має кастомну систему управління чергою відтворення.

## ✨ Основні можливості

* **Offline-First підхід (Кешування):** Дані про пісні, виконавців, список улюбленого та поточний стан плеєра (навіть час відтворення) надійно зберігаються у `localStorage`. Це гарантує миттєве завантаження додатку після оновлення сторінки (F5) без втрати даних.
* **Розумна черга відтворення:** Під капотом працює кастомна структура даних `PriorityQueue` для ефективного управління чергою, а також реалізовано алгоритм-генератор для нескінченного випадкового відтворення (Shuffle).
* **Валідація аудіо:** Додаток автоматично робить `HEAD`-запити до аудіофайлів перед їх завантаженням, щоб відфільтрувати биті посилання і гарантувати стабільне відтворення.
* **Профілі виконавців:** Динамічні сторінки артистів (роутинг), де відображається їхня дискографія.
* **Кастомний UI:** Плеєр містить повністю стилізовані з нуля повзунки (Range Sliders) для контролю гучності та прогресу треку з динамічним заповненням градієнтом.
* **Система улюбленого:** Користувачі можуть додавати треки до списку "Favourite", який синхронізується з локальною пам'яттю.

## 🛠 Технологічний стек

* **Core:** React 18 (Функціональні компоненти, кастомне використання `useState`, `useEffect`, `useRef`)
* **Роутинг:** React Router (`react-router-dom`)
* **Стилізація:** CSS (з використанням кастомних псевдоелементів для Webkit/Moz)
* **Асинхронні операції:** Fetch API, AbortController для скасування запитів при розмонтуванні компонентів.

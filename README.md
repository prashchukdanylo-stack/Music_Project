# 🎵 React Music Player

Повноцінний веб-плеєр для прослуховування музики, створений за допомогою React. Проєкт побудований на сучасних підходах до розробки, має чисту модульну архітектуру, розширене управління станом та власну систему подій.

## ✨ Основні можливості

*   **🎧 Управління відтворенням:** Play, Pause, Next, Previous.
*   **🔀 Просунутий Shuffle:** Розумна система випадкового відтворення, яка використовує JavaScript-генератори та окрему чергу для збереження логіки треків.
*   **❤️ Улюблені треки:** Можливість додавати пісні до списку улюблених із збереженням стану.
*   **🎚️ Контроль гучності та часу:** Інтерактивні повзунки для зміни гучності та перемотування треку. Останній час відтворення та гучність зберігаються у `localStorage`.
*   **📜 Тексти пісень:** Окремий екран для перегляду текстів (Lyrics Viewer).
*   **📂 Гнучка черга:** Можливість додавати пісні в чергу (Queue) та динамічно нею керувати.

## 🛠 Технології та Інструменти

*   **React 18+** (Функціональні компоненти, Hooks)
*   **React Router DOM v6** (Навігація між плеєром, текстами пісень та авторами)
*   **Context API** (Глобальний стейт-менеджмент замість Redux/Zustand)
*   **Custom Event Bus** (Власна система подій `emitter` для зв'язку між незалежними компонентами)
*   **LocalStorage API** (Для збереження налаштувань користувача)

## 🏗 Архітектура проєкту

Проєкт дотримується принципу **Single Responsibility** (Єдиної відповідальності). Глобальний стан розділено на кілька незалежних контекстів для оптимізації рендерів:

*   `PlayerContext` — керує станом аудіо (відтворення, пауза, поточний трек, шафл).
*   `QueueContext` — відповідає за масив черги відтворення.
*   `TimeContext` — керує прогресом та часом поточного треку.
*   `LibraryContext` — зберігає список усіх пісень та улюблених треків (Favorites).

**Основна структура папок:**
\`\`\`text
src/
├── components/          # Візуальні компоненти (PlayerControls, SongDetails, Ranges, Heart, Shuffle)
├── contexts/            # React Contexts (PlayerContext, QueueContext, etc.)
├── hooks/               # Кастомні хуки (useStorage, etc.)
├── pages/               # Сторінки екранів (Player, Lyrics, Author)
└── utils/               # Допоміжні функції (logger.js, eventBus.js, formatTime.js)
\`\`\`

## 💡 Цікаві технічні рішення

*   **Custom Logger:** Розроблено власну функцію обгортку `logger`, яка безпечно логує як синхронні функції, так і асинхронні `Promises`, полегшуючи дебагінг.
*   **Безпечна робота з подіями:** Використання патерну Event Emitter дозволяє відв'язати логіку перемикання таймерів від React-рендерів (наприклад, події `timeExpire`, `songEnded`).
*   **Оптимізація рендеру:** Компоненти, такі як списки пісень, обгорнуті в `React.memo` для запобігання зайвих перемальовок.
